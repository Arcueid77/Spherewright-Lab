# Spherewright-Sample

Private executable scenarios, operational handoffs, and black-box acceptance evidence for [Spherewright](https://github.com/AvaloNero/Spherewright).

The product remains one monorepo. This repository consumes an exact product commit through `deps/Spherewright`; it does not implement reusable Plugin, MCP, Contracts, or Bridge.Core capabilities.

The initial import is prepared on a review branch. It does not publish v0.4.0, deploy software, or authorize any game action.
