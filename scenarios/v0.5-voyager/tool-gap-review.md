# Native operation tool gaps / 原生操作工具缺口复核

Owner direction, 2026-10-28: add tools instead of Computer Use; ordinary operations should keep DSP running and use its menu. This review distinguishes observed product gaps, existing capabilities needing better readback, and caller mistakes. It grants no new world, progress rollback, resource budget or publication authority. Items below are proposals unless explicitly marked implemented; build/tests are not installed-runtime acceptance.

所有者于2026-10-28要求增加工具，不使用Computer Use；普通操作保留游戏进程，使用原生菜单。本清单区分实际产品缺口、已有接口的信息不足和调用端错误，不增加另一世界、回退、资源或发布权限。除标明已实现外均为待实现方案；构建测试不是实装验收。

## Existing capabilities and fixes / 已有能力及应修问题

- Resource inspection and Native Harvest already cover harvestable rocks/ice; add identification, not another removal primitive. / 已有资源检查和原生采集可处理可采石头/冰晶，缺的是识别关联。
- Normal Save and the explicit paused quarantine-preservation branch exist. Strengthen complete-file coverage readback instead of creating competing Save variants. / 普通保存及暂停隔离保全已存在，应补完整覆盖读回，不堆保存变体。
- Exact same-session idle-quarantine reconciliation can Resume after fresh proof. It is distinct from ordinary Continue and from a load/restart. / 已有同会话闲置隔离复核可在证明后原地继续，须与普通继续和读档重启区分。
- Original retained miner/ILS adoption and construction-drone setting restoration are validation/entry defects; they do not require tools to fabricate buildings, reset outcomes or force-enable drones. / 原矿机/ILS接管和无人机开关恢复属于入口/校验缺陷，不需造建筑、重置结果或强开无人机工具。
- Active-vessel, station cargo, power, resource and production reads already support logistics evidence. Collect actual cycles/consumption; another observational wrapper cannot replace Gate2. / 已有船运、站货物、电力、矿源和生产读取，须完成真实航次及消费，不能用新观察包装替代Gate2。

## Execution order / 执行顺序

Finish the current menu-return slice through exact source qualification and same-source installation, replace the abandoned UI caller with public MCP, then continue the remaining real Gate2 logistics and final review pair. The pause/coverage work is the next minimal usability slice; another-slot switching, order cancellation and route batching are separately scoped proposals and must not become a prerequisite to finishing the current Gate2 route.

先把当前回菜单切片完成准确源码验证及同源实装，调用端改用公开MCP并停用原UI方案，再贯通剩余真实物流和最终双包。暂停/覆盖是下一最小易用性切片；其他存档切换、指令取消和整路移动分别定界，不把它们变成本次Gate2的前置框架工程。
