# Shared live driver / 共享实机驱动

One versioned implementation owns launch, public recovery, original-action reconciliation, normal save/close and complete protected backups. Per-run files contain immutable configuration and private input only; no imports from old `.local` execution code. `launch.py` starts exactly one detached `run.py`, audits actual caller/game lifetime separation, then returns while that same writer continues. Native source/cohort, current complete backup, real SDK arguments and first operation must be qualified before launch. / 启动、公开恢复、原动作核销、正常保存退出及完整备份统一版本化；每轮只给不可变配置和私有输入，不再导入旧执行代码。启动唯一分离writer并核真实生命周期，全部资格和首操作开游戏前完成。

`pause_handcraft_poll.py` can reduce an already running home handcraft's redundant polling without editing its immutable caller limits. It proves the original accepted action/recipe, healthy owned home, exact Python caller intent and process creation identity, then suspends only that caller. Game and MCP processes continue normally. Its observer admits only SDK-checked reads of the original action; terminal, bounded timeout, early resume request or observation failure always resumes the same caller in `finally`. It never pauses simulation, resets counters, resubmits an action or claims idle/Save coverage. Observer consumption remains separately recorded. / 长母星制造可仅暂停已核身份的Python轮询调用器，游戏和MCP不暂停；只读核原动作，终态、有限超时、恢复请求或观察异常均在finally恢复同一调用器，不改预算、计数、存档或重放动作，观察消耗另计。

`build-source.ps1` validates a clean exact source, Native build, relevant regressions, actual source SDK metadata and documentation before staging. `saved_space.py` separates exact paused LastExit data access from healthy execution. The `exact-paused-space` profile requires exact tick/mode echoes and the sole opening quarantine; its first actual work may be one native UI partial-chamber supply, with synchronous count/inc conservation. Subsequent space steps admit reads or the explicitly finite original-home return only. Native landing plus a covering normal save must restore healthy context before ordinary factory steps. New immutable native return records are included in complete backups. `preserve_stopped_space.py` can preserve a known failed return only after exact plan/handle and fresh native paused-cut proof; unknown outcomes never enter that branch. / 干净准确源码、原生构建、相关回归、真实SDK元数据及文档先统一核验再暂存。精确太空保存配置区分暂停数据访问与健康执行；首笔实操可为原生部分补舱，须即时核数量/增产点守恒。后续太空步骤只允读或明确有限的原母星返航，原生落地及完整正常保存后才转健康工厂上下文。新不可变返航记录纳入完整备份；已知失败仅在精确方案/原句柄和新鲜原生暂停切面证明后保全，不接收unknown。

`factory.py` executes finite public Native steps and accepts immutable hash-bound continuation plans in its output directory, without a second writer or shell evaluation. A caller error or unaccepted prepare refusal keeps a healthy world in the same writer; accepted failures and unknown outcomes retain their original handle and prohibit replay. Native funding readiness always requires fresh prepare. `contracts.py` handles the real pure-pole null-network DTO branch without claiming pole membership; that still requires full power evidence. / 工厂步骤及续接计划经公开Native接口执行；调用错误或未接受拒绝不退出健康世界，accepted失败/unknown保留原动作，不重放；充能等待以fresh prepare决定。纯电塔null网络字段不适用，不单独证明归属。

Only `exact-paused-space/open_saved_last_exit` may supply `consumedSavedIdentityToken` when no current Native hint exists. This is a private prior public identity input to the new Native data-only derivation, never the old plan/key or an outcome attestation. The final Native prepare still decides; the driver captures the fresh public saved-data identity before committing so a later failure cannot lose its ancestry. / 只有精确太空LastExit配置可在无当前原生提示时提供已消费身份token；它仅供新Native只读数据身份派生，不是旧方案/键或结果背书。最后仍以新鲜Native prepare为准，提交前保存新公开数据身份提示，后续失败也不丢身份来源。

The paused Sail role requires Native `frozenSavedPoseVerified`, not an absolute-speed cutoff. UI progress additionally requires equal nonempty `frozenSpacePoseBefore/After` and `spaceMomentumPreserved=true`. See the [complete pause/momentum audit](../../paused-space-model-audit.md); ground support and zero local tails remain separate. / 暂停Sail角色必须有原生完整冻结证明，不能用绝对速度阈值冒充；UI实操还须证明前后同一非空动量指纹。完整审计见链接，地表支撑及局部零尾部门独立保留。

`saved-home-return` first work binds a known-failed predecessor and its exact remaining ticks, including when the home factory is resident but the actor remains Sail. Startup may verify the original macro's Native paid thrust debit plus motion effect; acceptance alone never passes. The same writer then waits that exact handle through strict landing/normal save before executing another plan. First-effect evidence is not terminal success. / 当前保存续接首操作绑定原已知失败及精确剩余额度，工厂驻留不等于Walk。启动门可验证原长动作的原生推力付费与运动效果，不能只凭accepted；同writer随后仍核销该句柄至严格落地/正常保存，再开始下一计划，效果证明不冒充终态成功。

`stage-runtime.ps1`, `stage-singlefile.ps1`, `qualify-runtime.ps1`, `install-runtime.ps1` and `install_preflight.py` provide parameterized same-source development staging/qualification and the official atomic installer. Qualification requires the exact successful product CI, metadata/embedded-guide parity, coherent payload and public-SDK host classification. They create no distribution archives or publication. `Runtime.verify_backup` and `backup_after_normal_close` bind the current complete four-role Native files and all protected durable records. / 同源开发暂存、资格和官方原子安装亦共享参数化；准确CI、元数据/指南、同源载荷及SDK分类不省略，不生成发行双包或正式发布；完整备份绑定当前四角色及全部持久保护记录。

Evidence layers remain separate: production replay, SDK admission, source CI, disk installation, loaded modules and actual offworld state change. The startup gate remains300 seconds/120 target. Finite later stage/window/RPC allowances follow the current owner grant while preserving cumulative spending and all material/return/energy/warper limits. / 生产回放、SDK、源码CI、磁盘安装、加载模块及外星实际变化分开；启动门仍300秒/120目标，后续有限工作预算适用当前授权并保留实耗和物料/返航/能源/翘曲器限制。

`probe_installed.py` repeats stopped-process, exact inventory/PE and complete-backup checks in the detached writer's real filesystem context without opening the game. Desktop-virtualized and external-process path aliases can resolve equally inside the app yet expose different MCP directories externally; keep the independently verified physical runtime path in launch inputs. Installer aliases remain bound to the official transaction's original records. / 独立执行进程可先只读核关停、精确文件/PE及完整备份；桌面虚拟路径在应用内等价，不代表外部进程看到同一MCP目录。启动输入须采用独立核验的实际运行路径，安装别名仍遵守官方事务原记录。

Continuation envelopes may bind `requiresCompletedPlanSequence` to an earlier plan in the same caller; only its actual complete receipt admits the dependent plan. Independent corrections after a known refusal use a new immutable plan and fresh Native observations. An operation may opt into `freshStaleMaximumSeconds` (at most60 seconds/16 attempts): only an explicit Native `STALE_STATE` before acceptance permits fresh reads and prepare, each retaining a distinct evidence role. This never retries an accepted handle, timeout or unknown submission. / 续接可绑定同一caller的前序实际完成回执；已知拒绝后的独立修正须用新计划和新鲜观测。仅明确未接受的STALE可在有限额度内重新读取/准备，每次保留独立原件；不重试accepted、超时或unknown提交。

The enable-only mecha warper checkbox uses player observations for both first-work and ordinary configuration. Its original terminal readback must prove false→true, complete whole-package/chamber preservation and equal count/inc; it is not a replenishment or flight receipt. Voyager previews expose `routeStateHash`, not `stateHash`. Cold launch/normal close retain the actual prior writer RPC baseline. Installer target aliases must be proved to identify the same directory and satisfy the unchanged official archive validator; retain old metadata and any undispatched failure. / 翘曲器开关首操作/普通配置均绑定玩家；完整原终态须证明设置变更和库存守恒。路线哈希字段为routeStateHash。冷启动/正常关闭继承实际RPC基线；安装路径映射须证明同一目录并通过原官方归档门，保留原件。

Cold startup has an explicit closed→process-observed→complete OS job proof/module proof→menu→owned recovery→real first-work lifecycle. `job_lifetime_capture.py` inventories every observed application-owned job handle (including sibling owners and shared handles), pins process creation identities and excludes Game/Steam from the application process tree and all applicable cleanup groups. Group counts/flag combinations vary by host; an unreported kernel object address retains a separate owner/handle identity, never an absent-job inference. Unresolved owned handles or relevant unknown memberships reject. Unrelated system jobs are not claimed complete. Harmless probe certificates cannot qualify a game. `module-stamps.ps1` reads PE identities without executing assemblies; stale source/module hashes fail offline before launch. A pre-recovery audit failure signals the original writer to preserve/close only an unopened world; it cannot automatically save an already loaded healthy world. / 冷启动按完整生命周期核验，进程组数量不作安全依据；应用所有权句柄完整覆盖、进程创建身份和未知拒绝保留。内核对象地址未报告时按独立owner/handle记账，不视为无Job。模块身份开游戏前核验；失败保全不得自动保存已加载健康世界。 [Windows job membership API](https://learn.microsoft.com/en-us/windows/win32/api/jobapi/nf-jobapi-isprocessinjob).
