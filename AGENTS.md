Shared-history rewriting requires an explicit owner request, protected local backups, exact old/new ref and tree checks, and an exact-ref force-with-lease. Never use plain force, rewrite unrelated work or delete old tags. Prefer separate linear commits without an extra merge commit; ordinary changes use normal pushes. The product split merge and the bounded 2026-10-16 removal of its extra merge commits were explicitly owner-authorized, not standing permission for another rewrite.

Review all reachable history and the exposed PR/issue/Actions metadata, logs and artifacts before making private material public. Classify synthetic code and standard SSH principals contextually; do not print secrets or silently treat unexamined surfaces as clean. Keep immutable archive/manifests/locks unchanged unless a separately authorized evidence migration is necessary.
